## Getting started

- Clone the repository and add `Movements` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Movements/Assets/Scenes/Sample 2.unity](https://github.com/kleberandrade/genetic-algorithm-unity/blob/master/Movements/Assets/Scenes/Sample%202.unity), [Movements/Assets/Scenes/SampleScene.unity](https://github.com/kleberandrade/genetic-algorithm-unity/blob/master/Movements/Assets/Scenes/SampleScene.unity).
